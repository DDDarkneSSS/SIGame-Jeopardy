# SIGame Custom Edition

This app was created with AI, and solves the problem with limits for creating packs in the original SIGame. 

It is designed for the quick and simple creation of packs for "SIGame" (Jeopardy) and serves as a custom interpretation of the established internet version.

## 🎮 How to Play
The application works **completely offline**. 
To play with friends, you will need a good internet connection and a screen-sharing tool (like Discord, Telegram, or Zoom) so the host can broadcast the game screen. 
The host acts as the game master: they manage the session and click the buttons/categories that the players call out.

## ✨ Features
The following features are available in the game:
* **Player Cards:** Create player cards and assign available emojis to them.
* **Built-in Pack Editor:** Create your own custom game packs. *(Note: This feature is disabled by default. You can enable it in the Settings).*
  * Create a new pack and manage its structural components: rounds, categories, and questions.
  * Custom naming for rounds, categories, and individual questions.
  * **Media Support:** When creating or editing a question, you can attach media file(s) to add audio-visual accompaniment to the question if needed.
* **Pack Management:** You can easily save or load your question packs. All packs are managed via the `packs` folder, which is located in the same directory as the executable (`.exe`) file.

## 🎮 Как играть
Приложение работает **без интернета (офлайн)**. 
Для игры с друзьями необходима хорошая связь и программа для демонстрации экрана (например, Discord или Telegram), чтобы хост (ведущий) мог передавать картинку приложения. Хост полностью управляет сессией и нажимает кнопки, которые называют игроки.

## ✨ Доступный функционал
В игре доступно:
* **Карточки игроков:** создание карточек игроков с доступными эмодзи.
* **Встроенный редактор паков:** создание паков благодаря встроенному редактору *(по умолчанию функция отключена, вы можете включить её в настройках)*:
  * создание нового пака и его составных частей (раунд, категория, вопрос);
  * возможность наименования раундов, категорий и вопросов;
  * **Поддержка медиа:** при создании и редактировании вопроса возможно прикрепить медиафайл(ы) для создания визуально-аудиального сопровождения в вопросе, если это необходимо.
* **Управление паками:** если необходимо сохранить или загрузить пак вопросов, то это можно сделать через папку `packs`, располагающуюся рядом с `.exe` файлом.
